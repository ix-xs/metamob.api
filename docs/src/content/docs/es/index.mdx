## Un primer ejemplo

```ts
import { Metamob } from "@ix-xs/metamob.api";

const metamob = new Metamob({ apiKey: process.env.METAMOB_API_KEY });

const [quest] = await metamob.quests.list();

if (quest) {
  const needed = metamob.quests.monsters(quest.slug, { status: "needed" });
  const missing = await needed.count();
  console.log(`${quest.character_name}: ${missing} monsters to go`);
}
```

## Antes de empezar

Necesitas Node.js 20 o posterior, y una cuenta en [metamob.fr](https://www.metamob.fr) para crear una clave API. La guía da por hecho que conoces las bases de JavaScript, en particular `async` y `await`.

El paquete también funciona con Bun, con Deno, en un navegador y en las plataformas edge: consulta [Entornos de ejecución](/reference/runtimes/).

## Sobre Metamob

[Metamob](https://www.metamob.fr) es el sitio donde los jugadores de Dofus siguen sus misiones de archimonstruos y encuentran con quién intercambiar. El sitio, sus datos y su API son obra suya: esta biblioteca solo la llama. La [documentación oficial de la API](https://www.metamob.fr/help/api) sigue siendo la referencia.
