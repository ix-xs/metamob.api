## A first example

```ts
import { Metamob } from "@ix-xs/metamob.api";

const metamob = new Metamob({ apiKey: process.env.METAMOB_API_KEY });

const [quest] = await metamob.quests.list();

if (quest) {
  const needed = metamob.quests.monsters(quest.slug, { status: "needed" });
  const missing = await needed.count();
  console.log(`${quest.character_name}: ${missing} monsters to go`);
}
```

## Before you start

You need Node.js 20 or newer, and an account on [metamob.fr](https://www.metamob.fr) to create an API key. The guide assumes you know the basics of JavaScript, in particular `async` and `await`.

The package also works with Bun, Deno, in a browser and on edge platforms: see [Runtimes](/reference/runtimes/).

## About Metamob

[Metamob](https://www.metamob.fr) is the site where Dofus players track their archmonster quests and find who to trade with. The site, its data and its API are its work: this library only calls it. The [official API documentation](https://www.metamob.fr/help/api) remains the reference.
