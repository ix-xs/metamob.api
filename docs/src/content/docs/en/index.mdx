This guide teaches you how to use **metamob.api**, from installation to a
script that follows your quest. Each step tells you **what to do** and
**why**.

## What metamob.api is

[Metamob](https://www.metamob.fr) is the site where Dofus players track their
archmonster quests and find who to trade with. Its API gives a program access
to the same information: your quests, the monsters, the other players, the
messages.

metamob.api is a JavaScript and TypeScript client for that API. It covers its
42 endpoints, with their types:

```ts
import { Metamob } from "@ix-xs/metamob.api";

const metamob = new Metamob();

const [quest] = await metamob.quests.list();
if (quest) await metamob.quests.setMonster(quest.slug, "Pioukas la Plante", 1);
```

| What the package does | What it means for you |
| --- | --- |
| It knows the type of every answer | Your editor suggests the fields and flags typos |
| It takes monster names in French, English and Spanish | `"Pioukas la Plante"` instead of its id |
| It walks through paginated lists | `for await` reads every page, one request per page |
| It counts the 60 requests a minute of your key | A call over the limit waits its turn instead of failing |
| It ships the monsters, zones and servers | Searching that data sends no request |

## What you should know first

- **The basics of JavaScript**: functions, objects, `import`, `async` and
  `await`.
- **How to open a terminal** in a folder and type a command there.
- **An account on [metamob.fr](https://www.metamob.fr)** with at least one
  quest, to create your key.

The guide uses TypeScript, which Node.js runs as is. Everything also works in
JavaScript: just leave the types out.

## How to read this guide

- A code block with a **file name** is a file to create, or to replace, at
  that location.
- An API name written as code, like `metamob.quests.list()`, leads to its
  page in the reference.
- The terminals play when they come into view, and **Replay** runs them
  again. What they show is what the code of the page really printed, on an
  example account.
- **Next**, at the bottom of the page, takes you to the following step.

## About Metamob

[Metamob](https://www.metamob.fr) is a fan site. The site, its data and its
API are its work: this library only calls it. The
[official API documentation](https://www.metamob.fr/help/api) remains the
reference.
