<section class="at-section">
  <header data-reveal><span>02</span><h2>What you stop writing</h2></header>
  <ul class="at-points">
    <li data-reveal><h3>Id lookups</h3><p>Monsters, zones, subzones, servers and kinds of monsters go by their name, their id or the object another call returned. The names ship with the package.</p></li>
    <li data-reveal><h3>Limit and offset loops</h3><p>Every list can be awaited for one page or walked with <code>for await</code>. Pages are fetched as you go, at the largest size the API accepts.</p></li>
    <li data-reveal><h3>Sleeps between requests</h3><p>The client counts 60 requests a minute per key and makes the next one wait its turn. A loop over a whole quest slows down instead of hitting a 429.</p></li>
    <li data-reveal><h3>Batches of 200</h3><p>Give <code>setMonsters</code> a whole quest, as a list, an object keyed by name or a Map. It is split, sent in order and merged back.</p></li>
    <li data-reveal><h3>Status code checks</h3><p>A call returns the data or throws an error with a typed <code>code</code>. A typo in a name comes back with the closest names, before it can touch a quest.</p></li>
    <li data-reveal><h3>One client per player</h3><p><code>metamob.withKey(theirKey)</code> acts for a player who gave you their key, with the same cache and settings, and their own rate limit window.</p></li>
  </ul>
</section>
