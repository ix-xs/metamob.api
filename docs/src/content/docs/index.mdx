## Un premier exemple

```ts
import { Metamob } from "@ix-xs/metamob.api";

const metamob = new Metamob({ apiKey: process.env.METAMOB_API_KEY });

const [quest] = await metamob.quests.list();

if (quest) {
  const needed = metamob.quests.monsters(quest.slug, { status: "needed" });
  const missing = await needed.count();
  console.log(`${quest.character_name}: ${missing} monsters to go`);
}
```

## Avant de commencer

Il vous faut Node.js 20 ou plus récent, et un compte sur [metamob.fr](https://www.metamob.fr) pour créer une clé API. Le guide suppose que vous connaissez les bases de JavaScript, en particulier `async` et `await`.

Le paquet fonctionne aussi avec Bun, Deno, dans un navigateur et sur les plateformes edge : voir [Environnements d'exécution](/reference/runtimes/).

## À propos de Metamob

[Metamob](https://www.metamob.fr) est le site où les joueurs de Dofus suivent leurs quêtes d'archimonstres et trouvent avec qui échanger. Le site, ses données et son API sont son travail : cette bibliothèque ne fait que l'appeler. La [documentation officielle de l'API](https://www.metamob.fr/help/api) reste la référence.
